# Frostpunk -- Settings

**status:** research-integrated
**last_reconciled:** 2026-06-02

Recommended game settings for Frostpunk (PC / Steam), focused on the options that meaningfully affect city-view clarity or difficulty perception.

> **Menu-tab note:** the research did not confirm Frostpunk's exact in-game settings-menu tab names. The headings below group options by function; treat the tab labels as **unverified** until checked in-game.

## Graphics (tab name unverified)
Available graphics options: **Resolution, VSync, Shadow, Texture, Snow, Particle, Fullscreen AA, Ambient Occlusion, Global Illumination, Depth of Field.** The most performance-intensive (affecting large-city view readability): **Shadows, Snow, Ambient Occlusion.** Lowering **Snow / Particles improves clarity during storms**, when the city view gets dark/obscured.
_source: Deep Research handoff 2026-06-02 (3 sources) · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_

## Accessibility (gap)
**No dedicated colorblind mode and no UI-scale / text-size slider exist in the base game** -- a notable accessibility gap. Players who need heat-zone clarity rely on the **temperature overlay (hotkey O)** rather than color cues.
_source: Deep Research handoff 2026-06-02 (3 sources) · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_

## Difficulty
Set **per-scenario** via "Select Scenario" → Scenario Settings. A New Home defaults to **Medium** with no in-line difficulty choice unless you enter via Select Scenario. See `mechanics.md` Difficulty Modes.
_source: Deep Research handoff 2026-06-02 · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_

## Known config fix
Windowed-mode and resolution can be edited via **gfxconfig.ini / config.bin** in `%appdata%/11bitstudios/Frostpunk` -- the community fix for the "input not supported" launch bug.
