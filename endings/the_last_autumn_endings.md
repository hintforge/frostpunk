## Win state (one outcome, multiple text variants)

The Last Autumn has one win state: **Generator built + all people evacuated**. Outcome text varies based on choices made during the run. `spoiler: late-game`

## Text variant drivers `spoiler: story`

| Driver | Variants |
|---|---|
| Early departure (all stages done before Day 37) vs waiting for icebreaker to Day 45 | Distinct departure-narration text |
| All 3 Generator upgrades built + zero construction faults (Perfectionist) | "Complete generator" text variant |
| Worker vs Engineer allegiance + which Labour/Administration laws signed | End summary evaluates labour ethics (collective bargaining vs strike-busting/class division) |
| Kept the Winterhome parts vs returned them | Affects narration |

## Defeat conditions `spoiler: late-game`

- **Repeated milestone-deadline failure** -- IEC terminates the project (game over).
- **Failing to have anyone alive when the icebreaker arrives** -- evacuation fails = loss.
- **Maxed discontent causing total work stoppage** -- does not instantly end the game but cascades to failure if not corrected.
