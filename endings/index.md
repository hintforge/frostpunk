# Endings -- Index (Frostpunk)

**status:** research-integrated
**last_reconciled:** 2026-06-02

Frostpunk has multiple ending conditions per scenario. Each scenario can end in success or failure; some scenarios have multiple success variants. This folder tracks the conditions and consequences for each.

## Ending files

| File | Scenario | Ending types |
|---|---|---|
| `a_new_home_endings.md` | A New Home | The Saviour vs The Iron Saviour; Golden Path; failure conditions |
| `refugees_endings.md` | The Refugees | The Union (optimal) vs other outcomes |
| `arks_endings.md` | The Arks | Own win gate; New Manchester relief arc (both-cities best ending) |
| `winterhome_endings.md` | The Fall of Winterhome | Evacuation (Land Dreadnought) success vs failure |
| `the_last_autumn_endings.md` | The Last Autumn (DLC) | One win state with text variants; defeat conditions |
| `on_the_edge_endings.md` | On The Edge (DLC) | Save vs Let New London Fall binary ending; defeat conditions |
