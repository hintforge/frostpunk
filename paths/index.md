# Paths -- Index (Frostpunk)

**status:** research-integrated
**last_reconciled:** 2026-06-02

Branching law paths in Frostpunk. The Book of Laws has two parallel structures:
- **Adaptation laws** (always available, shared base)
- **Purpose laws** (mid-scenario unlock, Faith path OR Order path -- mutually exclusive)

This folder documents each path: the specific laws, their Hope/Discontent effects, their impact on the ending, and the strategic consequences of choosing one over the other.

## Path files

| File | What it covers |
|---|---|
| `faith_path.md` | Faith law tree -- branch chain, "crossing the line" laws, New Faith terminal law, ending conditions |
| `order_path.md` | Order law tree -- branch chain, "crossing the line" laws, New Order terminal law, ending conditions |
| `adaptation_laws.md` | Shared Adaptation laws -- always-available base; full law table, mutual exclusivities, Golden Path safety |

## Routing notes

- **"Should I go Faith or Order?"** → check `items/builds.md` for strategic tradeoffs; check here for the specific law effects
- **"Which laws give me The Saviour ending?"** → `faith_path.md` (spoiler-tier gated)
- **"What does [specific law] do?"** → the relevant path file
- **"What happens if I repeal a law?"** → the relevant path file (some laws cannot be repealed)

## Key known facts (scaffold)

*Confirmed from Stage 0 research:*
- Faith and Order Purpose trees are mutually exclusive -- adopting one locks out the other
- The Adaptation tree is always available and is not mutually exclusive
- Purpose laws become available mid-scenario via a story trigger
- Law choices affect the ending of A New Home (The Saviour vs The Iron Saviour)
