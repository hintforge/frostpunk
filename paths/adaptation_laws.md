# Frostpunk -- Adaptation Laws

**status:** research-integrated
**last_reconciled:** 2026-06-02

The **Adaptation** tree is available from the start of every scenario and is **not** mutually exclusive with the Purpose trees (Faith / Order). Adaptation laws are problem-solving measures (food, health, housing, child policy, death management). **Laws cannot be repealed once signed**, and each carries a cooldown before the next can be enacted.

> **Golden Path note:** most Adaptation laws are safe for the A New Home "Golden Path" achievement, including Extended Shift, Organ Transplants, Overcrowding, and Prosthetics. **Soup does NOT fail Golden Path** (common myth). Golden Path is failed by harsh *abilities* (Triage, the Emergency Shift ability) or by citizen deaths / Needs Crises -- not by signing any single Adaptation law.

### Alternative Food Source (cannibalism)
The terminal node of the Food Additives branch is a **cannibalism** law, obtainable only via an intense-starvation event arc. Heavy Discontent penalty and sharp Hope drop.
_source: Deep Research handoff 2026-06-02 · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 3 · category: lore · spoiler: story_

### "A Frightened Patient" (Radical Treatment)
Signing Radical Treatment triggers a scripted event in which refusing an amputation results in a death. Relevant to "save everyone" achievement runs.
